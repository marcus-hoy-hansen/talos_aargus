# Versioned Resources

`grch38_MANE_v1.5.txt` is the FastSpliceAI transcript annotation table used
by the default GRCh38 scoring path. It is a small static input resource, not a
run cache. The table follows the FastSpliceAI annotation format and represents
MANE GRCh38 v1.5 transcript coordinates.

The FastSpliceAI implementation is maintained separately in
[MOMA-AUH/FastSpliceAI](https://github.com/MOMA-AUH/FastSpliceAI). The MANE
release source is documented by [NCBI MANE](https://www.ncbi.nlm.nih.gov/refseq/MANE/).

Large cohort-specific resources and generated SpliceAI caches remain outside
this repository.
